# Demonstration images

These 16 historical MBAOD images are for a quick PC smoke demonstration only. They are not the current RGB4 train/validation/Test split. Classes are drone, bird, airplane and helicopter. Original source details and file hashes are retained in provenance.json; `curated_test_path` refers to the historical dataset snapshot linked in [the archive](../archive/README.md). Do not report scores from these images as the full project benchmark.
